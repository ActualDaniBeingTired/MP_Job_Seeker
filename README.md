Medical Portal is a Digital Platform for Healthcare job-seeking Informations. 

Every HTML have a Navigation Bar and Footer. The navigation bar is used to speed up user navigation's trought the website. Allowing them to access Home, Jobs, About Us, Contact, and even a button to registrate their account. If they already signed in however, it will be replaced with their profile picture. The footer also act as a navigation bar to speed up navigation, browsing options, and more informations about Medical Portal can be found here.

The HTML consisted of 7 Pages, those are : 
1. AboutUs      : About Us page shows the company profile that explains more about Medical Portal's commitment, vision and missions. User can learn more from this page. 

2. Contact      : Contact page shows a more indepth contact list where user's can find Medical Portal's HQ, Email, and Phone Numbers. We also integrated a built in Google Map that show's where our HQ is located. There's even a "Send us a Message" section where User can email us for help, recruiment partnerships, and a whole lot more. 

3. HomePage     : HomePage shows the MainPage that has a Hero section with Job Titles that user can type in and filter the locations. Clicking the arrow will jump towards the Jobs Page with the same search and filtered location. There's also Healthcare Category in a form of cards that show's what kind of position are currently open at the moments. On the lower side, there's also a "Why" section that shows the reason why User should use Medical Portal than other Job-Seeking program. 

4. Jobs         : Jobs page have a Hero section that show's the job and it's location that the user has searched. Clicking the Search button will show's the available list of jobs that's currently available in a form of cards. There's also filter buttons by jobs, filter by Employment Type, and filter by Experience. There's also a button below that act as a page to limit the amount of jobs that can be viewed. It's designed this way to not overwhelm the user.

5. Profile      : This page acts as a profile where User can customize themselves and generate CV's that can be used to apply Jobs. In this page, user can customize name, profile picture, ability, and many more.

6. Registration : This page shows an indepth registration form where User will make their first account. It also acts as information collector to help them start up their profile, hence the Location, DoB, and Phone Number. Submitting will go straight to the Sign In Page.

7. SignIn       : This page shows a SignIn option where User who already made an account can login from this page without having to registrate again. They also have the option to keep themselves signed in. 

The Website has been totally revamped in October-November using the assistance of ClaudeAI to integrate it with better JSON, better functionality. Background of the websites has been completely revamped using Canva.
